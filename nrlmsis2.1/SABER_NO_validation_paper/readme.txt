DATA SAMPLES USED IN "Thermospheric nitric oxide from SABER: Local time 
                      dependence and validation against independent observations"
  The files in this directory contain the NO density data samples used for
  analysis and fitting in Wang et al. (2025).
  
REFERENCE
  Wang, N., Emmert, J. T., Jones, M., Mlynczak, M. G., and Funke, B. (2025). 
  Thermospheric   nitric oxide from SABER: Local time dependence and validation 
  against independent observations. Manuscript submitted to the Journal of 
  Geophysical Research - Space Physics. 

FILE DIRECTORY
  NO.01.txt - NO.15.txt
    Data samples used for exploratory local time fitting in NRLMSIS 2.1.
  NO.15.txt - NO.30.txt
    Data samples used to validate SABER nitric oxide density.

FORMAT OF TEXT DATA FILES
  GRPID: ID OF INSTRUMENT:
        94  UARS/HALOE
       121  TIMED/SABER
       126  ACE/FTS
       128  ENVISAT/MIPAS
       140  SNOE/UV
       222  ODIN/SMR
       227  AIM/SOFIE
  KIND: KIND OF MEASUREMENT:
        30  NO Number Density (cm^-3)
  JDAY: NUMBER OF DAYS SINCE JAN 1, 1970
  UTSEC: UNIVERSAL TIME (s)
  ALT: GEODETIC ALTITUDE (km)
  LAT: GEODETIC LATITUDE (deg)
  LON: GEODETIC LONGITUDE (deg)
  VAL: MEASUREMENT VALUE
